書体とアイコンのサンプル（同じ行部品を 4 つの書体で）

アイコンはすべて Lucide（ISC ライセンス、線幅 1.75px の一貫したストローク）を SVG で描画。Unicode 記号・絵文字は使わない。数字は等幅数字（tnum）。大見出しは字間を詰め、本文は 15px / 1.4。

A. Inter + Noto Sans JP欧文は Inter（optical size 対応の可変フォント）、和文は Noto Sans JP。Apple の SF に最も近い骨格で、数字と英字が締まる。
~120KB（サブセット配信）
B. IBM Plex Sans + Plex Sans JP欧文と和文が同じ設計思想で作られた唯一の組。少し個性がある。文字が大きめに見えるので 14.5px でも読める。
C. BIZ UDPGothicモリサワの UD 書体。和文の可読性は最高クラス。欧文は普通。「道具」の顔つきで、Apple 風ではないが誠実。
D. Zen Kaku Gothic New最初のバージョンで使っていたもの。柔らかい。参考。
