カラーデザイン

原則は 3 つ。① UI は無彩色で組む（背景 2 段、文字 3 段、区切り 2 段）。② 色は意味にだけ使い、意味は 4 つ（優先 = 赤、相手待ち = 琥珀、エージェント = 紫、選択と完了 = アクセント）。③ アクセントは 1 色だけで、装飾に使わない。ここではアクセントを 3 通り並べ、同じ画面をダークでも示す。

無彩色のスケール（ライト）

cell #ffffff
hover #f5f5f7
side #f0f0f3
sel-side #e3e3e8
ink3 #b0b0b5
ink2 #6e6e73
ink #1d1d1f

背景は白（#fff）と、ごく薄い灰（#f5f5f7 / #f0f0f3）の 2 段だけ。純粋な灰ではなく、わずかに青みを含む（Apple の systemGray 系と同じ）。区切り線は黒の 14% と 24% の 2 段で、色を持たない。

アクセント 3 案 + ダーク（同じ画面）

A. 青#0a66ff · Apple/Things 系
B. 黒#1d1d1f · 無彩色一色
C. 橙#f2620f · 温かい一点
A · ダーク#4d8cff on #1c1c1e

推奨は A（青）。「選択」「完了」「リンク」を同じ 1 色で示せて、赤・琥珀・紫の意味色と衝突しない。B は最も静かだが、完了とリンクが黒になり「押せる」ことが弱くなる。C は個性が出るが、琥珀（相手待ち）と近く、意味色として混ざる。
